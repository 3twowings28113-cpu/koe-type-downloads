# koe-type（コエタイプ）

声で、文字入力。キーボードを打つ代わりに、喋るだけ。
喋った内容が、カーソルの場所にそのまま文章として入ります。

- **ずっと無料**（月額なし）
- **精度が高い**（日本語専用の音声認識エンジン）
- **音声は PC の外に出ません**（全部 PC の中で処理します）

## 入れ方（Windows）

1. 落とした zip を右クリック →「すべて展開」
2. 出てきたフォルダの中の「setup.cmd」をダブルクリック
3. あとは画面の案内どおりに進むだけ（モデルは自動で入ります。途中でショートカットキーを決める画面が出ます）

使い方は、文字を入れたい場所をクリックして、決めたキーを押して喋るだけ。もう一回押すと止まって、文章が入ります。

## できること

### 1. 音声入力

- そのまま変換（喋った内容をそのまま文字にする）
- 整えて変換（句読点や言い回しを、読みやすい文章に自動で整形）
- 表記を整える（略語や外来語の表記のゆれをそろえる）
- 辞書登録（人名・専門用語を登録すると、その通りに出る）
- 直すと、覚える（修正したところを学習。同音異義語は候補から入れ替え）
- 履歴（前に喋った文章を、あとから貼り直せる）
- どこでも入る（Word・LINE・ブラウザ、カーソルの場所に直接）

### 2. クリップボード

- コピーした文章・画像・ファイル・スクショが自動で貯まる
- ダウンロードしたファイルを、フォルダを開かずに使える
- よく使うものを登録（ピン留め）しておける
- 貯めたものをドラッグ&ドロップで、そのままアプリへ持っていける
- 定型文を呼び出して、すぐ貼れる

### 3. 囲って検索

- 画面の気になる部分をドラッグで囲うだけ
- 囲った画面を、そのまま画像としてコピーできる
- 囲った部分を、そのまま検索できる（Google レンズ連携）
- 画面アシスタント（長押しで起動）

## 動作環境

- Windows 10 / 11
- Mac 版 Lite は Apple Silicon（M1 以降）専用です
